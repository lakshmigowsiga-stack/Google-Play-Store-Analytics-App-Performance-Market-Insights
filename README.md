# 📱 Google Play Store App Performance & User Engagement Analytics

## 📌 Project Description

A data analytics project focused on analyzing Google Play Store applications to understand **app popularity, user engagement, ratings, pricing, and category-wise performance**.

The analysis uses **Python** for data cleaning, data transformation, feature engineering, exploratory data analysis, and statistical analysis, followed by **Power BI** for interactive dashboard development and business insights.

The project aims to identify factors influencing app popularity and user engagement, analyze customer ratings and reviews, compare free and paid applications, and provide data-driven insights that can help app developers and business teams improve app performance.

## 📊 Dataset

**Dataset:** Google Play Store Apps Dataset

**Dataset Size:** Approximately 10,000+ app records

**Format:** CSV

**Region:** Google Play Store

**Source:** Kaggle / Public Google Play Store Dataset

**Dataset Link:** https://raw.githubusercontent.com/MainakRepositor/Datasets/master/googleplaystore.csv

### Dataset Features

The dataset contains information related to:

- App name
- App category
- User ratings
- Number of reviews
- App size
- Number of installs
- App type (Free/Paid)
- App price
- Content rating
- Genres
- Last updated date
- Current app version
- Minimum Android version

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze the distribution of applications across categories
- Identify the most popular app categories
- Analyze app ratings and rating distribution
- Study the relationship between ratings and user reviews
- Analyze app popularity using installation counts
- Compare free and paid applications
- Analyze app pricing patterns
- Identify categories with higher user engagement
- Analyze the relationship between reviews and installs
- Study app size distribution
- Analyze application update trends over time
- Identify factors associated with higher app popularity
- Generate actionable business insights and recommendations

## 🔍 Key Analysis Areas

### 📊 App Popularity
Analyze application installations, categories, and user reviews to identify popular apps and high-performing categories.

### ⭐ Rating Analysis
Evaluate rating distributions and compare average ratings across different categories and app types.

### 👥 User Engagement
Analyze reviews and installations to understand user engagement and identify highly engaged application categories.

### 💰 Pricing Analysis
Compare free and paid applications and analyze price distributions to understand pricing patterns.

### 📱 Category Performance
Identify categories with higher numbers of applications, installations, reviews, and ratings.

### 📅 Update Trends
Analyze the last updated date to understand application maintenance and update patterns over time.
